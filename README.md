
# Guidewire_hackthon
Smart Income Protection System for Delivery Workers Problem Statement Delivery workers, such as from Swiggy and Zomato, they lose their  income because of external factors like heavy rain, pollution, or curfews. Right now, there is no system to secure their daily earnings, which leads to financial instability. 

Our Objective the goal is to create an AI-powered insurance platform that automatically protects the income of delivery workers when disruptions happen. 

Our Target Persona Food delivery partners (Swiggy/Zomato) 

-Like how much they Work daily for income 
- How much they get affected by weather and environmental conditions
  
System workflow: 
- The user registrations  on the platforms 
- Selects a weekly insurance plan 
- The system monitors external conditions (weather, pollution, etc.) 
- If a disruption occurs, the system automatically triggers a claim 
- An instant payout is sent to the user
  
Weekly Pricing Model: 
The premium is calculated weekly which is based on:
- Location (whether it is rain-prone or not)
- Historical weather data
  Example: - Low-risk area → ₹20/week
           - High-risk area → ₹50/week
  
Parametric Triggers
 Automatic payouts occur when:
- Heavy rainfall exceeds a certain level
- Pollution levels surpass the limit
- Curfews or road restrictions are in place (No manual claim is needed)
 AI/ML Integration
- Risk Prediction Model
- Predicts the chances of disruption based on past data
- Dynamic Premium Calculation
- Adjusts the weekly price based on risk 
- Fraud Detection
- Identifies fake claims using location and activity data
  
Tech Stack
- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL
- AI/ML: Python (basic models)
- APIs: Weather API
  
Key Features
- Easy onboarding
- Weekly subscription model
- Automatic claim processing
- Real-time disruption tracking
- Instant payout simulation Future Scope
- Mobile app development
- Integration with real delivery platforms
- Improved AI for better predictions
